What GRPO changed, what it didn't, and what comes next.

What Improved

  • +8.5pp intent accuracy
  • +4.8pp action accuracy
  • +0.045 macro F1
  • Higher minority-action precision
  • 100% format compliance
  • ROUTE_CLAIM F1: 0.18 → 0.33
  • Domain gains: liquid_damage, charging

What Did Not

  • SEARCH_KB bias: 78% vs 20% gt
  • COMPLETE: never predicted
  • Missing info recall: 0%
  • Challenge set drops significantly
  • ESCALATE F1 slight regression
  • Class imbalance: unsolved

Next Steps

  • More diverse training data
  • SEARCH_KB penalty in reward
  • Rebalance reward for COMPLETE
  • Multi-turn episode structure
  • Additional epochs (carefully tested)
  • Real customer transcripts
